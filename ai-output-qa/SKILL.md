# 判断力:AI 输出质检

拿到 AI 回答,先别抄。**你当杠精的水平,决定 AI 产出的上限。**

## 质检三找

1. **数据来源**:数字有出处吗?是不是编的?(AI 最爱编统计和引用)
2. **因果逻辑**:结论真的跟着前提走吗?有没有跳步?
3. **现实可行性**:放到我的场景里,资源/时间/权限够吗?

## 信任分协议

- 1-10 分 + **一句扣分理由**(必须写,倒逼真思考)
- ≥8 分:可采用,标注保留点
- 5-7 分:改后用,列出必改项
- ≤4 分:弃用或重问,说明缺什么信息

## 输出格式

```
找茬:①来源__ ②逻辑__ ③可行性__
信任分:__/10,扣分理由:__
结论:采用/改后用/重问,理由:__
```

## 变体分析

发现 AI 一处硬伤后,**同批次内容大概率有同类问题**——回到三找清单把同类全挑出来再定分。
