# 提问力:四要素指令

AI 最怕"帮我写个方案"这种模糊话。任何请求强制补全四要素:

> **背景 + 任务 + 要求 + 格式**

- ❌ "写个减肥计划"
- ✅ "我(久坐上班族)要(3个月减10斤),要求(不饿肚子、在家练),请用**表格**给每周食谱和运动"

## 模板

```
背景:我是__,处于__情况
任务:帮我__,目的是__
要求:必须__,不要__,限制__
格式:用__(表格/清单/代码/字数)呈现
```

## 执行规则

1. 拿到用户的模糊描述 → 识别缺失要素 → **先问还是先猜?** 关键决策信息(目标/验收)必须问;风格细节可给默认值
2. 输出补全后的完整指令,每要素标注对应部分,让用户可直接复制使用
3. 大任务先让 AI 复述理解再执行——指令正确性在这一步就能验证
