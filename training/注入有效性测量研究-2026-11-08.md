# 注入有效性测量研究（2026-11-08 ZCode · 联网五源 · "学会了"的可测量定义）

> [状态:current] ｜ 作者标签：[ZCode] ｜ 检索锚：注入有效性 / context utilization / Ragas / DeepEval / 测量 / 学会 / 养料库
> **背景**：主人问"你确定dsh学会了？"——诚实答案是不确定。本轮查 2026 年怎么**测量** Agent 是否真的使用了注入的知识。

---

## 一、五源速览

| 源 | 核心思路 |
|---|---|
| Ragas | **Context Utilization 指标**：衡量检索/注入的上下文与正解的对齐程度 |
| DeepEval | LLM 输出评估框架：faithfulness/relevance/hallucination 检测 |
| [SkillSpector (NVIDIA)](https://github.com) | Agent 技能安全扫描器：检测注入漏洞和提示注入 |
| [proof-agent-verify](https://github.com) | **对抗验证：worker 和 verifier 是分离的 Agent**——"自验不是验" |
| [Awesome-Knowledge-Injection](https://github.com) | 知识注入研究 curated 列表（双语） |

## 二、核心发现 → DSH 映射

| 2026 方法 | DSH 现状 | 差距 |
|---|---|---|
| **Context Utilization**（注入的上下文被使用了多少） | ⚠ quiz 关键词匹配是粗粒度版本 | 缺少语义相似度评分 |
| **Faithfulness**（回答是否忠实于注入的上下文） | ⚠ quiz 查关键词但不查语义忠实性 | 同上 |
| **Adversarial Verification**（worker≠verifier 分离验证） | ✅ maker≠checker 已实现 | **领先** |
| **Skill Security Scanning**（技能安全扫描） | ⚠ inject_check 查注入链但没查技能内容安全 | 候选 |

## 三、判定

1. **DSH 的 maker≠checker 在学术上领先**（proof-agent-verify 确认这是最佳实践）
2. **quiz 的关键词匹配是 Context Utilization 的粗粒度版**——升级方向：加语义相似度评分（不需要新依赖，用余弦相似度即可）
3. **SkillSpector 是安全扫描候选**——但需要引入 NVIDIA 依赖，⏳ 等裁决
